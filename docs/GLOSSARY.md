# Glossary

Use these words in code, UI text, docs and pull requests.

- **Disagreement with the SRS** (§1.3): fix one of the two in a PR.
- **A word used two ways:** add a row here.
- **Names in the "In code" column** are the ones to use when a table, column or enum is first created. The design doc that creates each one confirms it.

| Term                        | Meaning                                                                                                                                               | In code                                                | Don't say                    |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ | ---------------------------- |
| Space                       | A venue a Host lists (café, library, co-working space)                                                                                                | `spaces`                                               | venue, hub, listing          |
| Zone                        | A named area inside a Space (quiet desks, rooms)                                                                                                      | `zones`                                                | area, section                |
| Unit                        | The smallest thing a Seeker can hold: a seat, a standing desk, or a whole room with a capacity                                                        | `units`, `unit_type`                                   | desk, spot, slot             |
| Seat map                    | The Host-built snap-grid layout of a Space's units                                                                                                    | `seat_map`                                             | floor plan, canvas           |
| Seat state                  | One of Available, Pending Payment, Reserved, Occupied, and nothing else (D-004)                                                                       | `available`, `pending_payment`, `reserved`, `occupied` | Maintenance, booked, free    |
| Reservation                 | The row that records a Seeker's hold on one unit                                                                                                      | `reservations`                                         | booking                      |
| Hold                        | A reservation that is still active: Pending Payment, Reserved or Occupied                                                                             | active reservation                                     | booking                      |
| Reserve-now                 | Holding only a unit that is open at that moment; no future bookings (D-001)                                                                           |                                                        | book ahead, schedule         |
| Payment window              | How long a unit stays Pending Payment before it returns to Available (FR-2.2). Set by the system                                                      | `payment_window`                                       | hold timer                   |
| Wait window                 | The time a paid, Reserved unit is kept while the Seeker travels. The Seeker picks it within the Host's bounds. SRS §1.3 calls it "Hold / Wait window" | `wait_window`                                          | hold timer                   |
| Reservation fee             | The sandbox fee that guarantees a hold. Forfeited on a no-show                                                                                        | `fee_amount`                                           | price, rate                  |
| Booking token               | The unique token shown as a QR code after payment                                                                                                     | `booking_token`                                        | ticket                       |
| Check-in                    | The Host scans or enters the booking token; Reserved becomes Occupied                                                                                 | `checked_in_at`                                        | arrival                      |
| No-show                     | No check-in before the wait window ends. The unit is released and the fee is forfeited                                                                | `no_show`                                              |                              |
| Check-out                   | The Seeker leaves; Occupied becomes Available                                                                                                         | `checked_out_at`                                       |                              |
| Curated tag                 | A platform-defined tag that powers search filters                                                                                                     | `curated`                                              | amenity (on its own)         |
| Custom tag                  | A Host's free-text tag, shown for display and never used as a filter                                                                                  | `custom`                                               |                              |
| Host-updated                | The availability label saying when the Host last changed it                                                                                           | `updated_at`                                           | real-time, live              |
| Seeker, Host, Administrator | The three roles                                                                                                                                       | `seeker`, `host`, `admin`                              | user (when a role is meant)  |
| Sandbox                     | The payment gateway's test mode; no real money moves                                                                                                  |                                                        | payment (without "sandbox")  |
| Story, task                 | A STORY-xx issue, and a TSK sub-issue under it                                                                                                        | `STORY-01`, `TSK-01.3`                                 | ticket, card (for the issue) |
| Worq                        | The public-facing product and application name shown in UI and browser titles (D-026)                                                                 | `Worq` (in UI / metadata)                              | Work, WorkQ                  |
| StudyHub                    | The internal project, repository (`studyhub`), package name, and academic course codename (D-026)                                                     | `studyhub` (in repo / packages)                        | StudyHub (in public UI copy) |
